Run one identical fault across two projects

  1. Choose two rows. Document exact software release and controller family for each. Use an approved demo or offline simulation where offered; otherwise fill the comparison using official help and P111 · Commission one complete air-handler sequence.
  2. Pick the same three points in each project: an occupied fan request, actual proving input and supply-air temperature. Record how each is mapped from controller to screen. Take one local or simulated snapshot and one view of the supervisory value.
  3. Hold the proof false with request true on the training copy, record the first disagreement and the delayed alarm, then restore the input. Compare time stamp convention, quality display and what clearing the source does to alarm history.
  4. Archive each project using the documented workflow. Record which tool can restore which layer, including any dependencies or licenses. A successful trend export is evidence for commissioning; document a separate backup and restoration record.
