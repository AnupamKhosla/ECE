P92

Inspect damaged laptop RAM and decide what is repairable

Separate edge contacts, small support components, SPD and BGA memory packages. Practise cold inspection before attempting board rework.

Time 35–60 minutes without powered reworkBefore this P26 SMD rework · P91 RAM test · T49 DRAM theory

Identify which layer could have failed

A SO-DIMM is a small circuit board. Its gold fingers join the laptop socket. Copper traces and small support components distribute signals and power. DRAM packages store bits. A separate serial presence detect (SPD) device or hub describes the module to the host. A DRAM cell has a microscopic transistor and capacitor formed inside the silicon. A soldering tool reaches packages and board joints, so it cannot replace a single failed cell. T49 · DRAM cells, x8 and ranks.

Watch. Compare the fixture, controlled heating and positioning needed for a BGA package. This is a process demonstration on training equipment. A scorched customer module is an inspection and disposition example for this lesson. PACE’s BGA installation and removal demonstration on YouTube.

For this lab use a disconnected, condemned donor and a matching reference module or clear photos of the same PCB revision. Collect a loupe, side light, ESD mat, small ruler and camera. Handle the edges. Keep any visibly burned, delaminated or shorted module out of a working laptop. Look for flaking pads, lifted tracks, solder splashes, corrosion and displaced parts. First distinguish damage from normal PCB features such as unpopulated pads and factory residue.

Practise an inspection without risking a second board

  1. Photograph both sides of the scrap module. Identify edge contacts, orientation notch, parts near the packages and one visible failure candidate. Copy the board code and memory chip code. Use the manufacturer’s package marking tool to narrow the chip identity. Compare the full datasheet, including density, organisation, package and voltage. Micron FBGA code lookup.

  2. Compare one documented path or component on two isolated matching modules. If a safe cold resistance check is possible, use the same probe polarity, range, nodes and settling time. Rails with many components in parallel can have low readings on healthy boards. A reading across a capacitor still in the circuit includes all parallel paths. Record a difference as a lead and trace which components share the rail.

  3. Pick the cheapest safe comparison that discriminates two causes. If a missing part is documented, sketch the pad locations and the fitted orientation. Practise the same package on a scrap SMD kit before working on the real module. For BGA, compare the process equipment in the video with your shop and decide whether to replace the module or refer it. P26 surface-mount practice.

Rehearse one confirmed component replacement

On a documented SMD practice kit, identify a 1 kΩ chip resistor with accessible pads and an isolated circuit path. Build or buy the kit for this exercise. With the kit unpowered, compare the resistor’s reading with a verified loose spare. Follow P26 to remove and replace that part. Inspect both pads for wetting and adjacent bridges. Compare the final reading with the reference in the same circuit state. Write which conclusions would change if that resistor were in parallel with other parts. Transfer the measurement and inspection method to the condemned SO-DIMM. Its parts still need independent identification before replacement.

What if the laptop reports the right size but fails addresses near the middle?

Capacity enumeration proves the host could identify and train enough of the module to report it. The failure might come from a cell, a whole data lane, timings, or a supply path. Diagnose using the slot/module swap and the board evidence. The error address alone cannot tell you which visible black package to remove.

Release decision

Document the symptom, part identification, comparison and the reason for replacing, repairing or rejecting it. After any actual repair, retest in a compatible host at normal settings with the P91 matrix. Burning, repeated errors or unresolved instability make the part unsuitable for sale as working memory.
