P139

Tune wheel speed and test recovery from saturation

Set a wheel speed, add a load and see how quickly the controller recovers. Keep the duty request and applied duty on your record so you can tell whether a larger command could help.

Time 50–75 minutesBefore this P42 · T31

Predict the unloaded and loaded speeds

The trainer uses a 20 ms control step. At full duty the unloaded steady speed is 200 rpm. At 50% it is 100 rpm. A disturbance at 2.5 s subtracts the equivalent of 40 rpm from the steady speed. A first-order response with a 0.22 s time constant moves the wheel toward that steady speed. Speed never goes below zero in this model. In the load test, predict 60 rpm in open loop and explain why the model uses 70% duty to hold 100 rpm after the load.

  1. Run open loop, then P. Both use a feedforward duty of target ÷ 200. P adds 0.004 duty per rpm of error. Compare the final values and explain the remaining P error. Once settled, the model gives approximately 60 rpm for open loop and 77.8 rpm for P.
  2. Use PI (same Kp, Ki = 0.018 duty/(rpm·s)) to reduce the remaining error. Record overshoot and the speed at 5 s. Compare with the same run using high gain (Kp = 0.020, Ki = 0.040) and 120 ms delay. Distinguish an oscillating response from a steady offset.
  3. Choose the 260 rpm test in regular PI. Compare anti-windup on and off. During the first 2 s the demanded speed exceeds physical capability. At 2 s the target drops. Look for requested duty still exceeding 100% even after the drop.
  4. Pick settings for this training plant that keep final error within 5 rpm on the load run. Save one failing and one passing response. State which conditions the test covered.
Check the model outcomes

At 5 s regular PI with no added measurement delay reads about 100 rpm on the load test. The delayed high-gain run is still oscillating. In the saturation run with regular PI and no added delay, the request at 2 s is about 305% with anti-windup off and 6% with it on. The driver applies only 0–100%. The clamped integrator lets the wheel decelerate promptly when the demand drops.
