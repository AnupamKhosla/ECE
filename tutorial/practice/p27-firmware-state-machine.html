P27

Program a timed controller that can stop

Build a small controller with a start button and a permissive switch. Test what happens when the user holds Start, opens the switch or resets the board.

Time 60 minBefore this P11, P15

Wire the trainer

Use a 5 V Arduino Uno, a pushbutton and a toggle switch. Connect the Start button between D2 and GND. Connect the toggle between D3 and GND. The internal pull-ups make an open contact read HIGH. D3 must be closed for the output to run. Use the built-in LED as the output. If you attach a logic analyser, connect its return to Arduino GND and check that its inputs tolerate 5 V.

Define the behaviour before uploading

Watch on YouTube · ✔ Multitask Arduino with State Machines (& Switch Debouncing) · Normal Universe - Chris Guichet
Track how the code lets a button event be handled while the other timed work continues. Use that same idea when you add the stop input.

Start on a new button press only when the permissive is closed. Run for up to five seconds. Opening the permissive overrides every start request and turns the LED off. Closing the permissive or powering on with Start held leaves the LED off. A new press during a run leaves the original timeout in effect.

const int startPin = 2;
    const int permissivePin = 3;
    const unsigned long debounceMs = 30;
    const unsigned long runMs = 5000;

    bool rawStart;
    bool stableStart;
    bool pressPermitted = false;
    bool running = false;
    unsigned long rawChangedAt;
    unsigned long startedAt;

    void setup() {
      pinMode(startPin, INPUT_PULLUP);
      pinMode(permissivePin, INPUT_PULLUP);
      pinMode(LED_BUILTIN, OUTPUT);
      digitalWrite(LED_BUILTIN, LOW);
      rawStart = stableStart = digitalRead(startPin) == LOW;
      rawChangedAt = millis();
    }

    void loop() {
      const unsigned long now = millis();
      const bool startHeld = digitalRead(startPin) == LOW;
      const bool permitted = digitalRead(permissivePin) == LOW;
      bool startPressed = false;

      if (startHeld != rawStart) {
        rawStart = startHeld;
        rawChangedAt = now;
        pressPermitted = startHeld && permitted;
      }
      if (!permitted) pressPermitted = false;
      if (rawStart != stableStart && now - rawChangedAt >= debounceMs) {
        stableStart = rawStart;
        startPressed = stableStart && pressPermitted;
      }

      if (!permitted) {
        running = false;
      } else if (running) {
        if (now - startedAt >= runMs) running = false;
      } else if (startPressed) {
        startedAt = now;
        running = true;
      }
      digitalWrite(LED_BUILTIN, running ? HIGH : LOW);
    }

Run the acceptance tests

  1. Normal request. Close the permissive and press Start. Record the approximate delay to ON and run time.

  2. Held button. Hold Start for more than five seconds. The LED turns off after one run. Release, then press again to start a second run.

  3. Interrupted run. Open the permissive midway. The LED turns off. Close the permissive while still holding Start and confirm the output stays off. Repeat by resetting while holding Start.

  4. Broken input wire. Unplug the permissive wire at the ground end. The pull-up makes the open circuit stop the output. Write why this software input belongs to the trainer and what a machine safety circuit would require from its approved design.

Why it works

T15 explains logic levels and pull-ups. T30 explains debounce, elapsed time and startup state. Arduino’s Blink Without Delay example demonstrates the elapsed-time pattern.
