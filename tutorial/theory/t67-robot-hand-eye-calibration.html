Hand-eye calibration for wrist and fixed cameras

A camera can measure a target precisely in its own image while the robot uses the wrong world position. Hand-eye calibration estimates the rigid mounting transform from paired robot poses and camera observations.

Time 40–60 minutesBefore this T36 · P143

Name the frame each transform maps into

Write T(a←b) for a transform that maps a point from frame b into frame a. With column vectors, apply the rightmost factor first. Robot reports supply Gᵢ = T(base←tool). The camera’s perspective pose estimate supplies Cᵢ = T(camera←target) for the image paired to the same robot pose. Here tool means the rigid flange or tool frame selected for the entire calibration.

The fixed-camera chain follows from the two ways to map the board into the base. The image route gives X Cᵢ. The robot route gives Gᵢ T(tool←target). Multiplying by Gᵢ⁻¹ puts both sides in tool coordinates. Use the same length unit for the robot translations and the board dimensions.

Remove the unknown constant board pose

Call the leftmost factor Mᵢ, so it is Gᵢ for a wrist camera and Gᵢ⁻¹ for a fixed camera. For two captures the invariant gives M₁ X C₁ = M₂ X C₂. Multiply by M₂⁻¹ on the left and by C₁⁻¹ on the right.

B = C₂ C₁⁻¹
A X = X B

The relative motions are observed in different frames. The same mount X explains them across capture pairs. The ideal problem needs motions around at least two nonparallel rotation axes. Many repeated turns about one axis leave mounting components underdetermined. Capture enough well-spread poses for the actual mounting geometry while keeping the target visible and rigid. Validate across frames and in physical space

  1. Image fit. Project the observed target’s known geometry back into its own image. Compute residual error in pixels. Exact robot timing is outside this calculation.
  2. Paired pose fit. Join each capture to robot feedback at exposure, with frame names, clock references and units retained. Check whether the rebuilt invariant is consistent across unused captures. Translation norm and relative rotation angle report different error modes.
  3. Independent station check. For the wrist setup, compare against a separately located target or witness feature in base coordinates. For the fixed setup, check the tool-mounted board reference or a separate witness pick. Closely agreeing results can share a calibration bias. Test near and far positions and the actual approach directions.

At a 200 mm offset, a 0.30° orientation error can move the predicted point by about 1.05 mm perpendicular to its rotation axis. Allocate error to orientation and translation based on the end feature you need to locate. Save raw observations and calibration version with each station result so a sensor replacement, lens change or mount movement can trigger a controlled retest.

A wrist camera is calibrated with 20 nearly identical hand rotations. Every image fits below 0.3 px. What should you check?

Check the rotation axes in the robot feedback. Add tilts about a second axis and retain independent test poses. Also verify camera-to-target and base-to-tool transform directions and inspect the join between image exposure and robot feedback. They can fail even when the image fit remains excellent.
