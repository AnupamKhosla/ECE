P151

Build and prove a pick path on a virtual industrial controller

Build a short pick-and-place routine on an offline controller. Measure whether the path stays clear and whether an interrupted job can resume with the correct part state.

Time 75–110 minutesBefore this P142 · P147

Keep your program, tooling and frames together

Use an offline e-Series PolyScope 5 simulator with a virtual robot and no equipment connection. The supplier download may require an account and an appropriate host environment. The steps use the 5.25-era software handbook. Match the manual to your installed version. You can also work the same approach, detour and clearance logic in the browser with P142 and rehearse part states with P149. Define the active tool centre point in the virtual installation. Note the transform from flange to TCP and the frame used to specify each waypoint. Choose positions within the model’s demonstrated reach. Use a sketch showing the pick surface, approach and place surface. Keep a saved copy of the simulated installation and program together so the same program can be tested with the same tool and feature frames.

Teach a path with stopping points

SegmentMoveWhat to observe
Park to pick approachMoveJ to the approach pointInspect the whole arm sweep. Joint interpolation can curve the tool path.
Approach to pickMoveL into the fixture, zero blend at pickLinear TCP travel into the part and an actual stopping point for contact.
Pick to retreatMoveL away along the insertion directionCheck clearance with the carried part envelope before transferring.
Transfer and placeMoveJ between clear approach points. MoveL into and out of placement.Retain the gripper load until release proof. Stop at the placement point.

Step through the sequence in the virtual controller. Compare the same two clear positions with MoveJ and MoveL and record where their TCP paths diverge. On the two-link trainer in P142, compare maximum x in the direct joint move with the straight tool move. Add blend only at an intermediate travel waypoint where the clearance allows rounding. Compare the time and corner path with blend set to zero, then restore zero blend at pick and placement. An emulator’s graphical view may omit workpiece and fixture geometry. Treat your sketch, configured models and the program trace as separate evidence. Universal Robots · Blend trajectories.

Demonstrate failure before handing over the program

In the virtual program, use a simulation-only variable for grip proof. Run once with a successful pick and once with proof false at the pick. In the failing run the sequence should stop or enter its training hold state before transfer. Change proof back to true and confirm the held run does not assume a new part merely because proof returned. Test restart with part disposition unknown using the P149 work record.

Use a copy of the installation with a known TCP change and repeat the virtual pose comparison. Log which reference changed, which moves depend on it and what you must revalidate. Keep the simulator version, program, installation, waypoint and move list, test results and open clearance items. Plant release uses the approved production configuration and installed tests.
