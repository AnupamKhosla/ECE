P117

Diagnose a Windows laptop that reaches firmware but fails to boot

Work through UEFI, drive detection, Windows Recovery Environment, Safe Mode and logged errors while preserving customer data.

Time 45–80 minutesBefore this P32, P116

Run three observations before trying a repair

  1. Use a spare Windows machine with a known backup and test account. Record whether you reach the OEM logo, firmware setup, Windows spinner and sign-in. A black display and absent power lights follow different routes.
  2. Read firmware storage and boot entries without changing setup. Run the targeted storage test if the drive is detected and stable. On a customer drive with read errors or valuable unbacked-up data, pause and scope recovery before running repair writes or extended stress.
  3. From a booting Windows test machine use Advanced startup to enter WinRE. On a non-booting test machine, follow Microsoft’s supported WinRE or matching recovery media route. Note what requests owner authentication. Let the owner enter recovery information through the supported interface if it is required.

Dell Support demonstrates its troubleshooting workflow for Windows freezes.

Use the smallest change that tests the hypothesis

With approval and a known-good backup on a practice machine, select Startup Repair for a Windows startup case. Record its message and retest. If the symptom began after a driver change and a supported Safe Mode session is stable, record the driver name and time before using an approved rollback. A Safe Mode success narrows the conditions. A storage error in both paths points back toward drive and controller checks.

On a system that boots, open Reliability Monitor and Event Viewer’s System log around the incident. Record timestamps and providers. Repeated storage timeouts, WHEA events or a specific driver fault can guide the next test. An unexpected shutdown event alone does not identify the failed part. Test cold boot, two restarts and the feature that triggered the fault. For storage testing use P93 · Qualify a used SATA or NVMe SSD without reading files, and for consent and handover use P122 · Protect laptop data and run a repeatable handover test.
