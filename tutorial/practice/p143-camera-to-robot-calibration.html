P143

Calibrate a fixed camera to a robot work frame

The camera reports a point in its own frame. Move the point into the robot work frame and compare with an independent measurement before using the result.

Time 60–90 minutesBefore this P43 · P45 · T36

Mark which frame owns each measurement

Use two labelled paper grids or a spreadsheet. This exercise starts with corrected metric coordinates on one flat plane. Intrinsic calibration and the mapping from images into that plane are already assumed. With camera C fixed relative to base B, use pB = RBCpC + tBC. R rotates camera coordinates into the base axes. t is the camera-frame origin expressed in base coordinates. To go back into C, subtract t before applying R’s transpose.

  1. Draw A→B in each frame. The camera’s +x becomes the base’s +y, so the planar rotation is +90°.
  2. Rotate A, then subtract it from the base observation of A. Write out the resulting formulas for x and y. Apply them to B and verify agreement.
  3. Predict the position of C and D. Calculate the Euclidean norm of each residual. The contract permits 2.0 mm per validation point and all must pass. Give a release decision. Apply the inverse transform to your prediction for D and check units and signs.
Check the transform and decision

xB = −yC + 420 and yB = xC + 100. Predictions for C and D are (370, 200) and (350, 240). Their errors are approximately 1.41 and 3.61 mm. Hold release. Compare edge points and repeated captures. A residual that grows with distance may indicate scale, distortion or angular error. Collect more spatially distributed references before assigning a cause.

Verify a real camera without a moving arm

Mount a phone or webcam above graph paper. Mark a work origin and two axes. Use the four corners of a rectangle on the plane to map image points into work coordinates with a planar perspective transform. Measure the printed rectangle with a ruler before using it as a reference. With OpenCV, supply four corresponding corners in the same order to getPerspectiveTransform and map point coordinates with perspectiveTransform. For a narrow field with roughly overhead mounting you can also start with the pixel-scale method in P45.

Hold out three points spread across the paper. Independently measure their work coordinates with the ruler and compare. Repeat with one target lifted on a block without changing the planar mapping. Then return the target to the paper and move the camera slightly. Log measured and predicted position, target height and camera mount revision. Explain why the plane or mounting change calls for a new model or calibration.

Transfer the method to 3D work

Intrinsics connect pixels and rays. A pose estimate or depth measurement adds geometry. Extrinsics relate camera, fixture and robot frames. TCP calibration separately relates the tool tip or grasp point to the flange. Check several target locations, heights and wrist orientations using a reference independent of the fitted transform. An error that rotates with the wrist suggests a TCP offset. A similar shift everywhere after a fixture moves suggests an outdated fixture frame. A growing error at a different height can indicate that a planar model is being used outside its calibrated plane.

For an eye-in-hand camera, the camera-to-tool transform is fixed and base-to-tool changes with the robot pose. Pair each image with the corresponding robot transform at capture time. Hand–eye solvers use several well-separated poses with rotations about different axes. Check the frame direction expected by the exact function. Keep capture time, calibration version, frame IDs and a held-out residual plot with the result. OpenCV calibration, pose and hand–eye interfaces.
