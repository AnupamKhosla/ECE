P129

Diagnose Lenovo Yoga Book display and keyboard faults

Work a dual-screen Yoga Book 9i case and distinguish it from the original Halo keyboard Yoga Book before ordering boards, cables or displays.

Time 65–95 minutesBefore this P116, P117, P121

Identify which Yoga Book is on the bench

The 2023 Yoga Book 9i 13IRU8, machine type 82YQ, has two OLED touch displays and a removable Bluetooth keyboard. The original Yoga Book YB1 line uses a separate Create Pad with a Halo touch keyboard on supported variants. There are Windows and Android versions of that earlier family. Use the full machine type and its own manual. The photos here show comparable latch and display connections. For the exact Yoga Book layout use the Lenovo disassembly videos and parts diagrams below.

Lenovo shows the on-screen keyboard and gestures on the 2023 Yoga Book 9i.

Test picture, touch and input as three different functions

  1. On a 13IRU8 with both screens normally usable, record whether the upper and lower display produce an image at the positions and modes described by Lenovo. Use Windows display identification and a known-good external display connection if needed. Check brightness and whether Windows sees one or two internal displays.
  2. With the Bluetooth keyboard moved away, test touch and pen independently on each screen with a simple local drawing. Then use Lenovo’s virtual keyboard gesture under the documented conditions. Working display and touch with only the virtual keyboard missing points you toward the Lenovo software and settings.
  3. Test the removable Bluetooth keyboard separately while its own battery is charged. Compare with a known-good USB keyboard and with the laptop’s on-screen keyboard. Record whether the problem occurs only during the keyboard placement or posture change that triggers a different view.
  4. If a screen or touch path remains absent, use the 82YQ removal video for the matching assembly to locate connectors and service limits. Compare parts using full type, upper/lower position and FRU. Isolate all feeds as Lenovo instructs before touching a ribbon. Never live-reseat a display connector. Retest both displays, touch and supported modes afterward.

Compare a first-generation Halo case

When the built-in touch keys stop on a working Windows YB1-X91F/L, compare Create Pad modes and verify the correct Lenovo Halo driver. Use a known-good external keyboard to distinguish the application from the integrated input. An Android YB1 needs the Android-specific support route. If the touch keyboard and Create Pad functions fail in several supported modes, document the full module path before accepting a mechanical or board repair.
