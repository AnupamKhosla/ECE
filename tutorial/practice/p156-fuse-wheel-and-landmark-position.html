P156

Fuse wheel travel with a landmark position

Run the same eight-leg route with wheel travel and intermittent landmark fixes. Compare error against a surveyed reference, tune the assumed sensor uncertainty and see what a gate does to a wrong landmark.

Time 60 minutesBefore this P140 · T63

Watch. In the localization clip, compare the sensor contributions and look for the pose estimate during changes of direction. PickNik Robotics · Fused localization and navigation video.

Work the first update

Each leg of this synthetic track is exactly 0.50 m. Wheel travel reads 0.52 m and 0.53 m on the first two legs. Start at x = 0 with 0.10 m initial standard deviation. Assume each wheel increment adds independent uncertainty with standard deviation 0.05 m. The first landmark appears after leg 2 at 1.02 m with 0.20 m standard deviation. Calculate the estimate, gain and standard deviation after that landmark. Keep three decimal places for comparison.

Run the same wheels through three observation logs

Run the replay to compare final position and find when each correction was applied.

  1. Run the default log and check leg 2 against your calculation. Find where wheel error grows fastest. Use the change in wheel increments and the survey to explain why.
  2. Keep the model fixed and select the blackout. Compare reported standard deviation at legs 2, 4 and 6, then observe what happens at leg 8 when a landmark returns.
  3. Choose the wrong landmark and toggle the gate. With the gate off, inspect the change in estimate and uncertainty at leg 4. A small reported spread can accompany a large actual error.
  4. Repeat with assumed wheel spread 0.15 m and landmark spread 0.40 m. Record the innovation and gate outcome. The input log stayed fixed while the assumed uncertainty changed. Write how you would estimate those spreads from real repeat data.
