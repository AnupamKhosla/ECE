P157

Route a mobile robot through a changing aisle

An empty robot takes a short route. With a larger load it needs the wider aisle. Reproduce a blocked run and prove what changes when a fresh observation clears a stale obstacle mark.

Time 45–65 minutesBefore this P141 · T64

Set the geometry and keep the same goal

Each square measures 0.25 m. Start at column 2, row 4 and finish at column 10, row 4. A vertical wall at column 6 has openings at row 4 and rows 7–9. Movement in the model is from cell centre to cell centre, one cardinal step at a time. The centre is blocked when a circular envelope touches an occupied square. The two envelope radii are 0.10 m and 0.23 m. Compare both with half the width of the narrow opening.

The grid combines a fixed wall with one optional obstacle mark at column 6, row 8. Treat the marked square as occupied until a valid simulated clearing observation reaches it.

Plan a route to see where the centre can travel.

  1. Run the empty vehicle with no crate. Mark the barrier crossing and record route length. Repeat loaded. The goal stays the same and the planned route changes.
  2. Keep the loaded vehicle and insert the crate. Then select the removed crate with blocked sightline. Explain why both produce the same planner result even though the real aisle differs.
  3. Apply a new clearing observation. Record the cell that changed and check that the opening is usable again. In a real trace find the observation time, the sensor frame and the valid transform that would support clearing.
  4. Make an acceptance table with payload, shortest available route, physical obstruction, current mark and outcome. Add a test that would catch a planner claiming a route with the wrong footprint selected.
Check the routes and clearance

For a 0.10 m radius the centre can pass row 4 with 25 mm of geometric margin on either side. The direct route is eight steps or 2.00 m. For 0.23 m the row 4 opening is blocked. The route through row 8 is sixteen steps or 4.00 m with the wider opening clear. A mark on the middle square blocks that wider opening for the loaded robot. Removing the crate and blocking the clearing view leaves the mark active.

The model isolates footprint clearance and observation state. Before applying the lesson in a fleet, check footprint orientation, allowable unknown space, costmap update rates, control behavior and installed safety validation. Nav2 · Costmap configuration.
