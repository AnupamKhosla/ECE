# Practical courses and Workbench skill coverage

Reviewed 20 November 2026. The Workbench uses these courses to choose skills and design home or simulator exercises. Formal assessment includes supervised practical performance and provider requirements. A Workbench record can show what was practised and where to continue.

## What the teaching resources do

| Course or practical guide | Observed teaching or assessment method | Change in the Workbench |
| --- | --- | --- |
| [TAFE NSW Certificate III in Electronics and Communications](https://www.tafensw.edu.au/course-areas/electrotechnology/courses/engineering--UEE30920-01) and [national UEE30920 units](https://training.gov.au/Training/Details/UEE30920) | The core includes DC work and diagnostics across power supplies, amplifiers, digital subsystems and communications. Options include computer repair, optics, security and antennae. | Added an amplifier fault lab and theory. Put network video, point tracing and equipment service next to the core bench route. |

| [Australian computer module repair unit UEEEC0055](https://training.gov.au/training/details/UEEEC0055), [Dell startup distinctions](https://www.dell.com/support/kbdoc/en-us/000125609/resolve-no-power-no-post-no-boot-or-no-video-issues-with-your-dell-computer) and [Framework service library](https://guides.frame.work/c/Framework_Laptop) | The trade unit calls for known faults across different module functions, testing after reassembly and reporting. P60 develops screen, airflow and input diagnosis before module work. |
| [Google Pixel troubleshooting](https://support.google.com/pixelphone/answer/6306624?hl=en), [Samsung component diagnostics](https://www.samsung.com/us/support/answer/ANS10001383/) and [iFixit Pixel 4a camera guide](https://www.ifixit.com/Guide/Google+Pixel+4a+Rear-Facing+Camera+Replacement/139566) | Vendor support works by symptom before replacement. iFixit shows exactly how far into a particular model the job goes. | P34 adds an independent audio comparison. P61 tests preview and saved capture, isolates the affected camera and shows the connector and board side on a donor. |
| [GSA commissioning guide](https://www.wbdg.org/FFC/GSA/gsa_commissioning_guide_2020.pdf), [Belimo room sensor guide](https://www.belimo.com/mam/general-documents/installation-instructions/belimo_01RT_installation-instructions.pdf) and [Siemens SCE](https://www.siemens.com/en-us/content/sce-educational-institutions/documents/) | Construction checks, drawings and point identity support later functional tests. | [Miller wire drive and gun troubleshooting](https://www.millerwelds.com/files/owners-manuals/o1325a_mil.pdf) | Symptoms are split by wire feed, work return and output. | [Raspberry Pi setup and diagnosis](https://www.raspberrypi.com/documentation/computers/configuration.html#led-warning-flash-codes) and [Eclipse Mosquitto client reference](https://mosquitto.org/man/mosquitto_sub-1.html) | Boot codes are separate from network and application state. A subscriber can display messages independently of a dashboard. | P16 separates local boot, link, address and service. P18 traces one sensor sample from serial output to a subscriber and the dashboard. |
| [Pololu Romi guide](https://www.pololu.com/docs/0J69/3.3), [Northwestern Modern Robotics](https://modernrobotics.northwestern.edu/chapters/chapter4/) and [OpenCV calibration](https://docs.opencv.org/4.x/d9/d0c/group__calib3d.html) | Count mode and gearbox identify the relationship to motion. P45 compares an untouched part against a reseated part before accepting an inspection tolerance. |
| [KiCad guided first project](https://docs.kicad.org/master/en/getting_started_in_kicad/getting_started_in_kicad.html), [ARRL dipoles](https://www.arrl.org/single-band-dipoles) and [FOA hands-on testing](https://www.thefoa.org/tech/ref/quickstart/test.html) | The part, fixture or reference must be known before interpreting a test. P53 rejects a passing loss number when the reference drifted. |
| [Axis Academy Network Video Fundamentals](https://www.axis.com/files/acad/Network_Video_Fundamentals_Course_Description.pdf) and [Camera Station operations](https://help.axis.com/en-us/axis-camera-station-pro) | Equipment, network, optics, installation and recording are distinct skills. The operator views and verifies stored video. | P62 commissions a single camera on a bench and uses actual playback, outage evidence and recorded timing as closing checks. |

## Route coverage checked

| Route | Practical result a learner can produce | Remaining coverage to develop |
| --- | --- | --- |
| Foundation and general repair | Name test points, account for loaded voltage and isolate a quiet amplifier fault. | Add an active filter or oscillator with measured waveforms and a real failed donor. |
| Welding equipment | Classify feed, work-return and output complaints. Demonstrate a bad connection on a low-voltage fixture. | Document more mentor-run return-to-service examples on specific inverter and wire-feed models. |
| Computer service | Differentiate boot, input, network, thermal and internal display symptoms. Keep a repeatable comparison before replacing anything. | Add model-matched wireless card and antenna service with a reception comparison and an approved data backup and restore exercise. |
| Android service | Relate a failed function to an intact one and verify optics, app, connector and module in order. | Extend to more Android families, haptics, cameras with multiple rear modules and specified calibration requirements. |
| BMS and field work | Locate and mark a room device, label both ends and see which raw and displayed points change. | Go further into retrofit constraints, airflow balancing and season-dependent checks with supervision. |
| Industrial automation | Compare hardwired input, program tag, permissives, output command and independent proof. | Add more accessible motor, electrical drawing and pneumatic test fixtures with measured timing. |
| Embedded, SBC and IoT | Prove local boot and link, then trace one sample through firmware, a broker and dashboard. | Add offline buffering and a replay test for a disconnected gateway. |
| Robots and vision | Measure encoder scale and sign, test position and separate repeatability from classification performance. | Add multi-axis servicing, alignment and real camera-to-robot calibration. |
| Design, test and energy | Match a real plug to its layout, probe known faults and compare logged power or sensor readings. | Add production sampling, an assembly inspection workbook and safe extra-low-voltage energy conversion test rigs. |
| RF, fibre and security | Repeat a reception comparison with noise context, check reference drift and prove recorded coverage. | Add an RF receiver stage, more connector inspection photos and recorder event tests with sample timestamps. |
