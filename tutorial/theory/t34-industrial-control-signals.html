T34

Control signals, PLC scans and independent proof

A button, an input bit, a command, a coil and a feedback contact can all disagree. Read each as evidence at a different boundary.

Time 30 minutesBefore this T16 · T17 · T31

Map the field signal to a controller value

Digital input means the electronics detect an electrical state at a terminal. Analogue input is sampled continuously and represented as numbers with scaling. Software also stores desired commands, alarms and communications status. A status tag may represent data from a local input, a remote device or a formula, so verify the map before trusting it.

Scans, asynchronous data and timing

Many cyclic controllers refresh an input image, execute logic and update outputs. Actual timing and immediate I/O vary by platform. A 10 ms task may miss a pulse shorter than its interval if no input latch or fast counter captures the pulse. A software timestamp may describe when the front end received a value. A field timestamp, quality and freshness limit help you detect stale samples.

Example. A 3 s proof timer begins when the command energises. If feedback starts after 3.4 s, the late transition can still leave a latched diagnostic. Record the event timeline and the reset policy.

Separate level, edge and acknowledgment

Imagine a fixture sends a 6 ms completion pulse to a PLC that reads its input every 10 ms. If the pulse occupies 11–17 ms and the task samples at 10 and 20 ms, both readings are low. Use an appropriate latched input, a fast counter, or a request held until acknowledged, depending on the interface. If an I/O module filters out the pulse before the PLC sees it, increasing the PLC task rate alone cannot recover it.

On a cyclic fieldbus, link status and value freshness are separate. A communications failure can leave the last value visible. Put the job ID and result together in one consistent update, and check them against the outstanding request. If the hardware exchanges multiple words without a consistent update guarantee, use the device’s documented consistency mechanism. P144 · Replay stale and delayed robot acknowledgments.

Command priority and machine safety

BACnet commandable objects can take commands at different priorities. A BMS operator command at 8 can mask a schedule at 16 until the command relinquishes. Physical feedback must be proved independently. An ordinary control interlock can help normal operation. Safety-related functions use equipment and design appropriate to the risk assessment, with validation by competent people.
