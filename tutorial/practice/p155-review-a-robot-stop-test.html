P155

Review a robot stop and restart acceptance record

The simulated cell stops every time on the test sheet. Check whether it stopped within the agreed boundary, remained held and required the right restart evidence.

Time 55–75 minutesBefore this P146 · T62

Read the test contract for a synthetic cell

This exercise uses recorded observations for a guarded stationary robot. The training contract sets a maximum of 450 ms from guard-request marker to the defined physical stopped state. Use an instrument uncertainty bound of ±10 ms on the full measured interval. An interval entirely below or equal to the limit supports a pass. An interval entirely above is a fail. A result spanning the limit is inconclusive. After the guard is restored the training scenario requires manual reset, then a distinct start command. The limits and names belong to this exercise. Qualified technicians use the applicable design and validated site procedure for equipment.

Check the measured intervals and decisions

A is 410 ms, bounded by 400–420 ms, and passes this case. B is 445 ms, bounded by 435–455 ms, and is inconclusive. C is 472 ms, bounded by 462–482 ms, and fails. Guard-to-drive intervals are 45, 46 and 47 ms. Drive-to-physical-stop intervals are 365, 399 and 425 ms. Investigate which conditions affect the later interval and retain the load, direction and profile in the repeat record.

Read the restart evidence as a second requirement

In the next record the guard closes at 2,480 ms and reset is acknowledged at 2,620 ms. Start is still held from the original cycle. The motion monitor reports movement at 2,630 ms. There is no fresh start event. Identify which requirement failed and how to reproduce it on the simulator. Include another trial with a start request only after readiness. Keep guard restoration, reset acknowledgement, new start request and actual motion on separate lines in your report.

In your release note identify the failed or inconclusive requirement, evidence and owner. For this record the stop limit and restart behaviour both need resolution. An individual passing run only covers its recorded setup. ISO 10218-2 · Robot cell scope.
