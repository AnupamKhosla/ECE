T37

Edge AI, dataset leakage and inspection metrics

An inspection model returns scores from camera data. An engineer still has to prove what those scores mean for the job.

Time 25 minutesBefore this T24 · T36

Choose the output the job uses

Classification labels an image or a region. Detection reports places where objects appear. Segmentation assigns labels pixel by pixel. A system locating a missing fastener may only need a known image patch. If the part needs an accurate outline, use a calibrated measurement stage or a segmentation output evaluated for that purpose.

Watch on YouTube · Watch detection on the device and note what the model outputs. Compare that with the measurement and reject/review rules you need. Edge Impulse Demonstration of FOMO: Constrained Object Detection on Embedded Devices · Edge AI and Vision Alliance.

A split is about independent evidence

Split by physical part, run or site where needed. Adjacent frames of the same part are highly correlated. Putting them in both training and testing can give an optimistic estimate. Validation data helps choose thresholds and settings. Once the model is fixed, the final test measures expected performance on independent data.

For defect detection, precision = TP/(TP+FP), recall = TP/(TP+FN), and defect miss rate = FN/(TP+FN). With only 5 defects in a batch of 100, passing everything reports 95% accuracy and zero recall on the defects. Specify which label is positive before you present metrics.

Build quality and timing around model output

A confidence score is a model output. Measure calibration before reading a score as a probability. Add a disposition for low confidence, impossible geometry, missing frames and excessive latency. Include capture, processing and decision timestamps. Models can shift after lighting, parts or camera settings change. Track held-out examples from genuine changes before releasing a revision.

In a simulated robot or inspection cell, use AI to make an inspection recommendation and keep physical motion authorisation in the validated control system. Edge Impulse learning material · NIST AI Risk Management Framework.
