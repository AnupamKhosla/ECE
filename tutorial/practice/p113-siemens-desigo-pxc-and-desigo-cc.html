P113

Trace a Siemens Desigo point from PXC to Desigo CC

Use a PXC or DXR training project to compare hardware I/O, BACnet objects and the management station at three different layers.

Time 75–120 minutesBefore this P38, P63, P111

Choose the tool that owns the layer

For the supported PXC4/5/7 and DXR families in this exercise, ABT Site is used for the automation project and controller engineering. Desigo Control Point supplies an operator interface on supported projects. Desigo CC is the management station where an integrated point can be displayed, trended or alarmed. Legacy PX and APOGEE projects can have different engineering tools and migration requirements. Identify controller label, firmware, installed project version and documented tool before working.

Siemens demonstrates the Desigo ABT Site engineering workflow.

Commission three readings in order

  1. Use a licensed PXC/DXR training controller and lab project, a supervised training environment or the document-only equivalent. Select one temperature input, one fan proof and one training command. Record input type, terminal, scaling, device instance and object instance in a single map.
  2. Using a documented simulator or safe ELV input approved for that hardware, create two values within the selected range. Confirm raw input and engineering value locally in the controller commissioning view. For example, a simulated 0–10 V point configured for 0–50 °C displays about 12.5 °C at 2.5 V and 37.5 °C at 7.5 V. Use a common return only on the documented input configuration.
  3. Match the BACnet object in the training Desigo CC project and identify it in System Browser or the assigned view. Compare value, units and quality at the same moment. Expose the point on a training graphic and trend those steps. Change the proof input while keeping the command fixed and log both timestamps.
  4. If the controller reads correctly but the management value is wrong, check mapping, quality and update rules first. If the controller is wrong too, return to the selected hardware input and scale. Restore the training values, review remaining overrides and save the controller project and management project according to the assigned handover procedure.

Document-only exercise. Use P111 · Commission one complete air-handler sequence to obtain the expected fan result and fill the three-layer worksheet with the Siemens model and feature references. Mark which rows still require hardware.
